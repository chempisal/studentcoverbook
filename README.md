* **Vector SVG**: ឯកសារវ៉ិចទ័រគ្មានដែនកំណត់ទំហំ សម្រាប់រោងពុម្ពធំៗ។
* **Template JSON File**: ទាញយក file គំរូទុក និងបើកលើម៉ាស៊ីនដទៃ។
* **Link ចែករំលែក (Instant Share URL)**: ចម្លង Link ផ្ញើតាម Telegram/Facebook បើកចេញគំរូដូចគ្នាបេះបិទ។

1. **បើកផ្ទាល់លើកុំព្យូទ័រ (Offline Ready)**:
